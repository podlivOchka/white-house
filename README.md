# White House — Каспийск

Каталог женской одежды White House, ул. Ленина, 39А.

Проект: React, TypeScript, Vite. Каталог, поиск, фильтры, карточки товаров, избранное, корзина и запрос заказа через WhatsApp.

Данные и фотографии перенесены из предоставленного владельцем примера. Наличие, размеры и окончательная стоимость подтверждаются консультантом.

Инструкции запуска и проверки будут добавлены вместе с исходниками.
