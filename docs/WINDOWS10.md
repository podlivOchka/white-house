# White House на компьютере с Windows 10

Сайт, админка, база товаров и загруженные фотографии могут работать на этом компьютере. Для первого локального запуска Docker не нужен. Интернет потребуется для загрузки проекта и установки зависимостей.

## Установка

1. Установите [Node.js 24 LTS](https://nodejs.org/en/download), выбрав Windows и архитектуру своего компьютера (обычно x64).
2. Установите [Git for Windows](https://git-scm.com/download/win).
3. Закройте и снова откройте PowerShell. Выполните:

```powershell
node --version
git --version
```

Версия Node.js должна начинаться с `v24.`. Команды ниже предназначены для обычного PowerShell; права администратора для запуска проекта не требуются. Используется `npm.cmd`, чтобы не менять политику выполнения PowerShell.

## Загрузка и первый запуск

```powershell
Set-Location $env:USERPROFILE
git clone --branch main https://github.com/podlivOchka/white-house.git
Set-Location white-house
if (!(Test-Path .env)) { Copy-Item .env.example .env }
npm.cmd ci
npm.cmd run admin:set
npm.cmd run build
npm.cmd start
```

Выполняйте команды по очереди. Если команда завершилась с ошибкой, сначала исправьте её, затем продолжайте.

`admin:set` возьмёт почту администратора из `ADMIN_EMAIL` в `.env` и дважды запросит новый пароль. Ввод скрыт, поэтому символы не появляются на экране. Минимум — 12 символов. Пароль задаётся на этом компьютере; публикация на GitHub не создаёт готовую учётную запись.

После запуска откройте в браузере:

- Сайт: http://localhost:3000
- Админка: http://localhost:3000/admin

Войдите с почтой из `.env` и своим паролем. Добавьте карточку в админке, затем откройте каталог — изменение должно быть видно без пересборки.

Для этого режима оставьте в `.env` значение `SITE_URL=http://localhost:3000`. По умолчанию сервер принимает подключения только с этого компьютера. `localhost` на телефоне указывает на сам телефон; этот адрес не является публичной ссылкой магазина.

## Следующие запуски

```powershell
Set-Location "$env:USERPROFILE\white-house"
npm.cmd start
```

Пока открыто это окно и компьютер работает, сайт доступен. Для остановки нажмите `Ctrl+C`. Повторно создавать администратора и собирать сайт каждый раз не нужно.

## Обновление сайта

Остановите сервер через `Ctrl+C`, затем выполните:

```powershell
git pull --ff-only origin main
npm.cmd ci
npm.cmd run build
npm.cmd start
```

Товары, фотографии и учётная запись находятся в `data`, поэтому обновление кода их сохраняет. Для резервной копии остановите сервер и скопируйте всю папку `data` на другой носитель. Она содержит также сведения учётной записи и не должна попадать в публичный репозиторий.

## Смена почты или пароля

В отдельном окне PowerShell из папки проекта:

```powershell
npm.cmd run admin:set -- --email новый-адрес@example.com
```

Команда заменит единственного администратора и завершит старые сеансы. Существующие товары сохранятся. Для изменения только пароля укажите текущую почту. Изменение `.env` само по себе не меняет уже созданный аккаунт.

## Публичный доступ

GitHub Pages показывает отдельную демонстрационную витрину. Изменения в локальной базе не синхронизируются с ней автоматически.

Для запуска полноценного магазина из дома отдельно настраиваются домен, HTTPS, внешний доступ через провайдера и роутер, автозапуск и резервные копии. Перед этим нужно проверить обновления системы и выяснить, предоставляет ли провайдер публичный адрес. Компьютер и интернет должны оставаться включёнными. Схема с Docker и Caddy описана в [SELF_HOSTING.md](SELF_HOSTING.md).
